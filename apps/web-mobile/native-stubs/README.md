# Integraciones nativas futuras

Estos archivos Kotlin conservan el prototipo del puente para impresora termica, pero no forman parte de la compilacion actual.

Expo genera el proyecto Android valido durante el build. Para activar la impresora sera necesario convertir este prototipo en un modulo Expo local, agregar su configuracion nativa y probarlo con un development build; Expo Go no puede cargar modulos nativos personalizados.
